# DTCC Twin

DTCC Twin provides the user-facing interface to DTCC Platform. It enables users
to explore and interact with digital twin data on the web, through projection
onto physical 3D-printed city models, and through other digital and physical
experiences.

This project is part of the
[Digital Twin Platform (DTCC Platform)](https://github.com/dtcc-platform/)
developed at the
[Digital Twin Cities Centre](https://dtcc.chalmers.se/)
supported by Sweden’s Innovation Agency Vinnova under Grant No. 2019-421 00041.
